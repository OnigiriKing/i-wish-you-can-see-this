<h2>About the project</h2>

<p>
  <strong>I Wish You Could Read This</strong> is a multilingual full-stack web
  application created as a public space for unsent messages, memories, grief,
  love, and words people could not say directly.
</p>

<p>
  Visitors can select a location on an interactive map, leave a message and
  explore messages shared by other users. The application also includes message
  reporting, community guidelines, legal information and a contact page.
</p>

<p>
  The frontend is built with React and TypeScript, while Node.js serverless
  functions handle API requests and communicate with a PostgreSQL database.
</p>

Live Demo:
<a href="https://i-wish-you-could-read-it.netlify.app">
  I Wish You Could Read This
</a>

<h3>Built with:</h3>

» React<br>
» TypeScript<br>
» Node.js<br>
» PostgreSQL<br>
» Netlify Functions<br>
» Tailwind CSS<br>
» React Leaflet / Leaflet<br>
» OpenStreetMap<br>
» React Router<br>
» i18next<br>
» Vite

<h3>Key features:</h3>

» Interactive world map with location-based messages<br>
» Creation and storage of public messages<br>
» Message reporting functionality<br>
» Node.js serverless API<br>
» PostgreSQL data persistence<br>
» English, Japanese, Korean and Russian language support<br>
» Responsive interface for desktop and mobile devices<br>
» Community guidelines, legal information and contact pages
